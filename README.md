# 餐桌地圖 · The Dining Atlas

餐桌地圖是一個非官方、獨立整理的 American Express 餐飲禮遇搜尋工具，讓你用名單及互動地圖探索香港與海外的參與餐廳。餐廳及禮遇可能隨時更改，預訂或付款前請查閱 [American Express 官方條款](https://www.americanexpress.com/zh-hk/benefits/diningbenefit/)。

## 功能

- 中文／English 介面，可用右上角按鈕切換並自動記住選擇。
- 按餐廳名稱或地址搜尋，並以地區、菜式、本地／海外範圍篩選。
- 在餐廳名單或地圖標記中選擇餐廳，查看地址、電話、官方網站、訂座連結及 Google Maps。
- 支援香港及多個海外地區；沒有可靠座標的餐廳仍會保留在名單中。
- 手機介面可在「餐廳名單」與「地圖探索」之間切換。

## 使用方法

1. 在右上角按 **EN／中文** 選擇介面語言。
2. 使用搜尋欄輸入餐廳名稱或地址。
3. 按需要選擇地區、菜式及本地／海外範圍；海外範圍亦可指定國家或地區。
4. 點選餐廳名單項目或地圖標記查看詳情。
5. 使用餐廳官網／訂座、電話、Google Maps 或 American Express 官方禮遇連結繼續操作。
6. 如需重新開始，按「清除篩選」；如需重新顯示所有可見餐廳位置，按「重設視野」。
